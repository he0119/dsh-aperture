# Agent Note: 组合层不写 config

Status: implemented

## Problem

本包自带一份 `cordis.patch.yml`（组合层）。补丁层是**整行替换**：`config-editor`
写下去的是整份 `next`，不会把与继承层相同的键逐个剔掉。而「已覆盖」的判据是**键在
不在用户层里**。两件事叠在一起，组合层里写什么就会被用户原样抄进自己的文件。

## Decision

组合层**故意不写 `config`**：缺省值只有 schema 一处。

## Alternatives considered

**把缺省值摆进组合层，让配置一眼看全。** 用户第一次在界面上保存就会把这些缺省值
全量抄进自己的文件，「已覆盖」的判据于是凭空为真；将来改动某个缺省值也会被那份
文件钉死——改 schema 不再改变任何人的行为。

**组合层写一份与 schema 缺省值保持一致的 `config`。** 一致性没有任何东西守着，
两份值迟早会分叉，而分叉之后以组合层为准，等于把缺省值搬到了一个没人会去看的地方。

## Consequences

- 缺省值只有 `src/config.ts` 一处，读组合层看不到任何一个。
- 组合层里出现 `config` 就是缺陷，而不是「显式声明」。
